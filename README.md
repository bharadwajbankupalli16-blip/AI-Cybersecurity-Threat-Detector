## 🛡️ AI-Based Cybersecurity Threat Detector

This project is an educational machine-learning application designed to analyze network traffic and identify potential cybersecurity threats. It uses a Random Forest Classifier to classify network activity as **Normal** or **Potential Threat** based on features such as packet size, connection duration, failed login attempts, requests per second, port number, and protocol.

The project includes an interactive **Streamlit dashboard** that allows users to enter network activity details, view predictions and threat probability, monitor prediction history, visualize dataset distribution, and examine the model's confusion matrix.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Streamlit
- Matplotlib
- Seaborn

> **Note:** This project is intended for educational and demonstration purposes and uses a small synthetic dataset. It is not a production intrusion detection system.
